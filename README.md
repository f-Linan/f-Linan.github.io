# f-linan.github.io

这是由 GitHub Copilot 聊天助手为你创建的个人网站仓库（默认模板，简洁专业）。

如何编辑

- 在仓库中编辑 `index.html` 和 `styles.css` 来替换文本、头像和样式。
- 如果你想替换头像，请把新的图片上传到 `assets/` 目录并修改 `index.html` 中的路径。
- 保存后 GitHub Pages 会自动部署更新（通常几分钟内生效）。

Pages 地址

https://f-linan.github.io

后续建议

- 上传你的简历 PDF（例如 `assets/resume.pdf`）并在页面中添加下载链接。
- 替换示例项目为你的真实项目并添加链接和截图。
- 如需多语言支持或博客功能，可以 later 改用 Jekyll/Hugo 或静态站点生成器。
